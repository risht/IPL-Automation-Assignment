# IPL Automation Assignment

A Java-based Selenium automation project for validating web workflows and UI scenarios around IPL-related content.

## Tech Stack

- Java
- Selenium WebDriver
- TestNG
- Maven

## What This Project Demonstrates

- UI automation and browser interaction
- Element identification and validation
- TestNG-based test execution
- Practical Selenium automation techniques

## Run

```bash
mvn clean test
```
